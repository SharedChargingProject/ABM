# Agent-based model for the SharedCharging project

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18841747.svg)](https://doi.org/10.5281/zenodo.18841747)
[![arXiv](https://img.shields.io/badge/arXiv-2604.27849-b31b1b.svg)](https://arxiv.org/abs/2604.27849)
[![SimPy](https://img.shields.io/badge/SimPy-discrete--event%20simulation-blue.svg)](https://simpy.readthedocs.io/)

This repository contains the simulation code for the paper **A Grid-Aware Agent-Based Model for Analyzing Electric Vehicle Charging Systems**.

The model is a configurable, grid-aware agent-based simulation environment for EV charging systems. It combines EV behavior, charging column constraints, and a shared Energy Sandbox for aggregate power allocation. The implementation is written in Python using SimPy.
